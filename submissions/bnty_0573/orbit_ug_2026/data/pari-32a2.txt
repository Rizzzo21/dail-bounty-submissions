HOW TO READ EACH LINE
---------------------

ellidentify    Confirms the curve is Cremona 32a2 and that the model
               [0,0,0,-1,0] is the minimal model.

ellglobalred   = [N, [c4,c6,...], v_2, conductor matrix, local data].
               N = 32 is the CONDUCTOR; the last entry [[5, 3, 0, 2]] lists
               (f_p, v_p(Delta), kodaira code, Tamagawa number) for the bad
               primes, so at p = 2 we read f_2 = 5, v_2(Delta_min) = 3 for the
               Kodaira-symbol code, and c_2 = 2.

elllocalred(2) = [f, kod, v, c] = [5, 3, [1,0,0,0], 2].
               Per ??elllocalred in THIS PARI version the enumeration is
               "1 means good reduction, 2, 3 and 4 mean types II, III and
               IV respectively, 4+nu with nu > 0 means type I_nu, finally the
               opposite values -1, -2, etc. refer to the starred types".
               So kod = 3 means TYPE III, and c = 2 is the TAMAGAWA NUMBER.
               The third component v = [u,r,s,t] is a coordinate-change
               record, NOT a discriminant valuation; u = 1 means the given
               equation was already minimal at p.

               NOTE ON THE KODAIRA LABEL.  Some tables (and the enumeration
               used by recent PARI/GP releases) label this reduction I_0*.
               That label is inconsistent with Ogg's formula
               f_p = v_p(Delta_min) + 1 - m: here v_2(Delta_min) = 6 and
               f_2 = 5, so m = 6 + 1 - 5 = 2 components, and type I_0* has
               FIVE components (it would force f_2 = 2, hence conductor 4,
               contradicting the conductor 32).  Type III has m = 2
               components, which is what Ogg's formula gives.  This artefact
               therefore says III, and the Tamagawa number -- the only
               quantity that enters the BSD identity -- is 2 either way.

elltors        = [order, structure, generators] = [4, [2,2], [[-1,0],[0,0]]].
               The torsion subgroup has order 4 and structure (Z/2)^2.
               (Independently PROVED by Fermat descent; see PROOF.md.)

ellrank        = [r, R, s, L] = [0, 0, 0, []].  Per ??ellrank the output is
               [r,R,s,L] with the rank between r and R, and s giving
               information on the Tate-Shafarevich group.  Here r = R = 0, so
               the rank is EXACTLY 0 (both bounds coincide).

               CAREFUL WITH s.  Per ??ellrank, s is the rank of
               G[2]/2G[4] and "the value s gives a minoration of S" (S =
               the 2-rank of the Tate-Shafarevich group).  So s = 0 does
               NOT by itself certify that Sha[2] = 0: PARI's own worked
               example (E = ellinit([-113^2,0]), also ellrank = [0,2,0,[]])
               has s = 0 while Sha is (Z/4Z)^2, whose 2-rank is 2.

               The correct inference uses the documented identity
               C = T + R + S together with R_upper = C - T, giving

                   S  =  R_upper - R_true.

               For our curve R_upper = r = 0, so S = 0, i.e. the 2-rank of
               Sha is 0 and Sha[2] is trivial.  src/sha2.py implements this
               inference AND validates it on PARI's own worked example,
               where it predicts S = 2 (the manual's stated answer).  This
               speaks to the 2-primary part only; the odd-primary part is
               NOT settled by a 2-descent and is CITED, not proved, here.
